# Fictive Systems Orchestrator — product overview

Fictive Systems Orchestrator is a workflow orchestration platform for moving
data between line-of-business systems. Pipelines are declared as versioned
plans; the platform schedules them, retries failures and records every step.

Two release lines are in the field. Orchestrator 3.x is the long-term support
line and receives fixes only. Orchestrator 4.x is the current line and the
target for all new integrations.

External systems connect through integration paths. Which path is supported
depends on the release line and, for some paths, on the customer's
entitlement tier — Standard or Premier. The authoritative statement of what
is supported on which line is the Fictive Systems support-status rule set;
individual documents in this corpus describe one path on one line each.
