# Contributing

Common Measure is source-available under the Functional Source License
(`LICENSE.md`). Contributions are welcome under the agreement below, which
every contributor accepts once, from the pull request, before a change is
merged. The agreement exists so that Common Measure Ltd can relax the licence
later, as the Functional Source License already promises for each release,
without having to find and ask every past contributor.

## How to contribute

1. Read `AGENTS.md` first: it states the repository rules, including truthful
   integration evidence, coordination and proportional validation. `PRODUCT.md`,
   `DECISIONS.md` and `ROADMAP.md` say what the product is, what constrains
   it and what is open.
2. Open a pull request against `main`. Keep it to one change with a commit
   message that states the fact and its reason.
3. Run the checks appropriate to your change, following `AGENTS.md`
   §Verification. Include the commands, results and remaining gaps in the
   pull request. Full workspace checks apply to release candidates and broad
   changes; prose edits need relevant documentation checks.

4. On your first pull request a check asks you to accept the contributor
   licence agreement below. Accept it by posting this comment on the pull
   request, exactly:

   ```text
   I have read the CLA Document and I hereby sign the CLA
   ```

   The acceptance is recorded once against your GitHub account, in the
   private repository `commonmeasure/cla-signatures` that Common Measure Ltd
   keeps for that purpose, and is not asked for again. Nothing is written to
   this repository.

Security problems go to hello@commonmeasure.ai (`SECURITY.md`), not to a
public issue. Questions about the agreement below, including accepting it
for an organisation, go to the same address.
