# Open findings

`gate.md` defines scoped review and release checks. This file owns unresolved
defects. Findings name evidence, consequence and closure; P2 improvements do
not block delivery. Close or retire with a fixing revision or reason. The
review's verdict applies to its named scope, not every unrelated task.

No finding is open. A gate that opens one adds its row to the table below.
